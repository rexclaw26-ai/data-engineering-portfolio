# Data Engineering Portfolio

A responsive personal data engineering portfolio built with a single HTML file, including embedded CSS and JavaScript.

## Features
- Responsive homepage, About, Projects, Skills, and Contact sections
- Dark/light mode
- Mobile navigation and project category filters
- Accessible focus styles and reduced-motion support
- Three **project concepts** clearly labeled as concepts, not completed work

## Personalize the content
Edit `index.html` to replace `Your Name`, `YOUR NAME`, and `your.email@example.com`. Review biography and skills for accuracy. Replace the project concepts with real projects and links to their repositories before using this portfolio for job applications.

## Preview
Open `index.html` in a browser.

## Publishing with GitHub Pages
In this repository, open **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/ (root)**, and save. The eventual URL should be `https://rexclaw26-ai.github.io/data-engineering-portfolio/` once GitHub completes the deployment.

No build tool or dependencies are needed.
